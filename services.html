OUR PROTOTYPE

Accessible authentication.
Built as two Android apps.

AccessOTP demonstrates an automatic one-time-code workflow inside a fictional banking environment, without reading SMS or manually typing a generated OTP.

WHAT THE SYSTEM PROVIDES

Two apps. One sign-in journey.

The Android prototype includes working inter-app messaging within a demo environment; it is not integrated into a real bank.

Demo bank app

Username, four-digit PIN, account creation and a simulated BHD dashboard with balance privacy, demo deposits, transfers and transaction history.

Android prototype

AccessOTP Authenticator

Runs on the same device, automatically processes the protected request, records the latest verification and returns an HMAC proof to the demo bank.

Android prototype

Accessibility features

Digit-vibration modes (Count, Morse, Off), hidden-number PIN entry, labeled controls and the ability to avoid manual OTP entry.

Android prototype
HOW IT WORKS

Verify automatically after a correct PIN.

The bank demo creates a fresh OTP challenge, exchanges protected messages with the Authenticator, and opens the account only after checking the returned proof.
