IMPORTANT NOTE

What this demonstration does — and doesn't — do

The animation illustrates an envisioned product flow using a fictional banking interface and JavaScript state changes. The username/password and trusted-device checks are simulated in client-side JavaScript, with publicly visible fictional values. Clicking device registration does not validate a real device. This demo does not connect to banks, verify real identities, generate real OTPs, or grant access to accounts. A production integration requires bank-approved device enrollment, device binding, explicit user authorization, and security controls.
