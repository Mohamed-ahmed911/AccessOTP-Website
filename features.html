IMPLEMENTED ANDROID FEATURES

Designed to reduce
manual OTP steps.

Features below are based on the supplied Android Studio source for the Demo Bank and AccessOTP Authenticator applications.

CORE AUTHENTICATION

What the prototype actually does

Username + four-digit PIN

The bank app asks for a demo username first, then a four-digit PIN on a numbered or hidden keypad. The default sample account is ahmed with PIN 1234.

Implemented in Android

Automatic OTP handling

After a correct PIN, the bank app generates a one-time code and sends a protected request to the Authenticator installed on the same device. The user does not read or type the OTP.

Implemented in Android

Same-device companion app

The Authenticator must be installed with the bank demo and signed with the matching signing key. If the bank cannot connect, authentication fails. No independent trusted-device registration screen is implemented.

Implemented in Android

Protected inter-app verification

The Android source uses signature-permission IPC, an Android Keystore RSA key, encrypted challenge data, HMAC-SHA256 proof, a 30-second freshness limit and in-memory replay checking.

Prototype security controls
ACCESSIBILITY AND DEMO BANKING

Everyday interactions included

Count / Morse / Off

Optional vibration feedback for PIN digits, including a two-groups-of-five pattern for zero in Count mode.

Private PIN keypad

Numbers can be hidden. Users select a digit by its keypad position and confirm it after vibration feedback.

Hidden balance & Feel balance

The balance is hidden by default. Users can reveal it or feel its digits through Count or Morse vibration, with a short separator tick and a long pulse for the decimal point.

Demo transactions

Send demo money, top up a fictional account and view transactions with the most recent entries first.

Authenticator activity

The companion app shows its latest verification result and includes Status, Vibration, Activity and Help screens.

Create demo account

Create a temporary account and choose a sample four-digit PIN. These sample details are not connected to actual financial accounts.

PLATFORM

Android Studio

Two Kotlin Android apps operating on the same device. Android 8+ (API 26) is the stated minimum.

TARGET USERS

Visually impaired users

Reduce steps requiring an OTP to be read, spoken aloud, remembered or manually entered.

CURRENT LIMITS

Proof of concept

No real-bank connection, full device enrollment or production server-side MFA. Physical-device and assistive-technology testing are still needed.
